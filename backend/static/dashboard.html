VERTICAL PROFILE

Height during mission

Connect to load height measurements.

GNSS altitudeBarometric estimateEKF ground estimate (datum-corrected height − 0.4 m)DEM terrain height

The barometric curve uses the first GNSS altitude as its offset and the first pressure sample as its reference. The EKF curve estimates phone height from GNSS and pressure after applying the DEM tile’s calibrated GNSS datum offset, then subtracts the fixed 0.4 m phone-to-ground distance. DEM terrain height is sampled from the local 1 m GeoTIFF only inside its 2.5 km footprint. GNSS altitude and DEM height may use different vertical reference frames, so do not interpret their difference as verified phone height above ground.

All 1,000 particles are rendered over the local topographic contours; opacity represents relative posterior weight. The untouched initial cloud remains visible in gray. GNSS position initializes the cloud and is shown only as evaluation truth; it does not update particle weights. GNSS speed and bearing intentionally drive this first motion model.
